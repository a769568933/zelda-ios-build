# iPhone touch-controls build

Build support for a floating left movement stick and a swipe camera for the owner's existing unsigned app. This repository contains open-source controls and build tools only. Game files, keys, existing app binaries and shader libraries are not uploaded.

Cloud compilation and simulator checks produce a touch module. The final unsigned IPA is assembled locally from the owner's original app. Native scene resolution and sustained 60 fps are separate, unverified work.
